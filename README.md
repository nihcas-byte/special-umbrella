## 🚢 How to Deploy to GitHub Pages

### Step 1: Commit & Push Changes to GitHub
Run the following in PowerShell from `c:\Projects\special-umbrella`:

```powershell
git add .
git commit -m "feat: customize portfolio and resume for Sachin Tomer"
git push -u origin main
```

### Step 2: Ensure GitHub Pages is Enabled
1. Open your repository on GitHub: [https://github.com/nihcas-byte/special-umbrella](https://github.com/nihcas-byte/special-umbrella)
2. Go to **Settings** &rarr; **Pages**.
3. Under **Build and deployment**, select **GitHub Actions** as the Source.
4. Your site will automatically deploy to:
   **`https://nihcas-byte.github.io/special-umbrella/`**
